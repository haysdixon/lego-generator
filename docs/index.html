New LEGO models from the bricks you already have

Each model here is built using only the parts of one LEGO set. The instructions are free. The generator that designs these models is open source, so you can make your own from any set.

Make your own

  1. Get the code from this project's GitHub repository: the source repository.
  2. Run pip install -r requirements.txt, then python get_data.py. This downloads the free parts data once.
  3. Pick a set you own and a shape file, then run make_model.py. The README walks through it.

To open the .ldr models yourself, use LeoCAD or BrickLink Studio (both free).
