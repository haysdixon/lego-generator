# Four animals from one LEGO 11045 box

All four build from a single 11045 Creative Colorful Bricks box (820 pieces) at the same time: 404 bricks in total.
They were generated in this order. Each later model only got the bricks the earlier ones left over.

| Model | Bricks | Steps | Instructions |
|---|---|---|---|
| Highland cow | 113 | 12 | [highland-instructions](highland-instructions/instructions.html) |
| Holstein cow | 125 | 12 | [holstein-instructions](holstein-instructions/instructions.html) |
| Long-neck dinosaur | 78 | 14 | [longneck-instructions](longneck-instructions/instructions.html) |
| Potbelly pig | 88 | 7 | [pig-instructions](pig-instructions/instructions.html) |

Some steps show red or blue bricks inside a model. They are hidden fillers and don't show once it's built.
The main README has the exact commands to rebuild these models.
